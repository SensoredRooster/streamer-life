# Streamer Life

**Streamer Life** is a numbers-first streamer-life simulation about 2026 creator reality. Live is a factory, shorts are a storefront, owned audience is a bunker, integrity is spendable, and burnout can beat a green graph.

Open `index.html` to play the vanilla HTML/CSS/JS prototype. See `docs/` for the locked brief, Act 1 script, and architecture.
